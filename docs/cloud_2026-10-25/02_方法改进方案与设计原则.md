# PSV 方法改进方案：更少 token 同样好 / 同样 token 更好，以及设计原则的来源

> 目标：在不破坏三条设计保证（P1 引用可追溯、P2 上下文有界、P3 有界终止）的前提下，找到能真正改善「成本—质量」前沿的变体，并给出每一条的机制、预期、风险、验证方式。
> 第二部分把道家、禅宗、儒家、基督教、计划 / 市场、经济学里的几条思想映射到具体机制上——它们是**设计原则的来源**，不是论文里要引的文献；论文里最多留一句。
> 第三部分用一个可运行的模拟（`sim/psv_cost_sim.py`）先在设计空间里把变体排个序，再决定花 API 预算跑哪一个。模拟结果见 `sim/README.md`。

## 一、先说清 PSV 现在的成本在哪、质量损失在哪

来自 tab_roles / tab_growth / tab_profile（Drafts48，中位数）：

| 事实 | 数字 | 含义 |
| --- | --- | --- |
| 每题调用 | 9–11 次，其中只有 2–3 次（规划器、比较物裁定、写作者）真正需要强模型 | 侦察员可以换便宜模型 |
| 侦察员 token 份额 | 48–57% | 省 token 的主战场在侦察 |
| 每篇打开文档的 token | PSV 2–4k vs ReAct 13–26k | PSV 的单位阅读成本已经很低，再省只能靠「少读没用的」和「写作者输入更紧」 |
| 打开文档 | 18–23 篇；金证据读到率 0.55–0.69 | 还有 1/3 的金没读到 |
| 金漏读的归因（Qwen） | 约 40% 是「计划没点那篇」，其余是「读了没出卡 / 卡没过 / 写作者没用」 | 固定计划是最大的质量瓶颈 |
| 核验器删卡率 | 0.3–11.2% | 闸挡掉的是弱模型的假引句；这也意味着**闸让便宜侦察员变得安全** |
| 并行重叠度 | 1.4–1.7（串行和 / 实际耗时） | 侦察员越多、越均匀，耗时越被压平 |

两条结论决定了下面的方向：
1. **省 token**：侦察员降级（省钱不省 token）、少读无用文档（省 token）、写作者输入去重（省 token）。
2. **提质量**：打破「计划一次定」却不引入 ReAct 式的无界循环——用**有界**的二次机会（跟随提及、一次重规划、按饱和停）。

## 二、变体清单（按「值得先试」排序）

每条给：机制 → 保证是否保持 → 预期 → 风险 → 怎么验证（优先用已有轨迹做回溯分析，零 API）。

### V1 · 分层侦察（PSV-T, tiered scouts）——省钱
- 机制：侦察员用便宜模型（同家族 Flash 档）；规划器、比较物身份裁定、写作者用强模型。
- 保证：P1–P3 不变（闸不依赖模型）。
- 预期：美元成本降 40–60%（侦察员占 48–57% token，价格差 5–10 倍）；token 不变；落地召回变化应在噪声内——因为便宜侦察员多出来的假引句会被闸删掉（tab_gate 里 Flash 档删卡率更高正是这个现象）。
- 卖点：**「闸是让便宜侦察员变得安全的那道东西」**——这是 PSV 独有的、ReAct 做不到的组合（ReAct 单模型无法分层）。
- 风险：便宜模型漏卡（读了金文档没出卡）。
- 验证：Drafts48 全 48 题，MiMo-Flash 侦察 + MiMo-Pro 规划 / 写作 vs 全 Pro；再做一组跨家族（Gemini-Flash 侦察 + Claude 写作）。看金读到率、卡产出率、落地召回、$。

### V2 · 词法预筛（PSV-L, lexical pre-screen）——省 token，零模型
- 机制：规划器点名后、侦察前，用 BM25 / 词项重叠把「子问题关键词 vs 文档」分数低于 τ 的文档剔掉，不派侦察员。
- 保证：不变。
- 预期：剔掉 20–40% 零产出文档，侦察 token 同比例下降。
- 风险：金文档词面重叠低被剔（艺术史里同一物件有多种称谓、多语言）。
- 验证（零 API，回溯）：对现有全部 PSV 轨迹，算每篇被侦察文档的预筛分数，画「阈值 τ → 剔掉的零卡文档比例 / 剔掉的金文档比例」两条曲线；若存在 τ 使金保留 ≥ 98% 且剔除 ≥ 25% 零卡文档，就采用。这是最便宜、最确定的一个改进。

### V3 · 卡片去重与按文档分组的写作者输入（PSV-D）——省 token，零风险
- 机制：同一文档的重复引句合并；文档元数据（题名、馆藏号、年代）每篇只给一次而不是每卡一次；卡按子问题分组、同组内按立场（支持 / 矛盾）并排。
- 保证：不变。
- 预期：写作者输入减 10–30%；并排矛盾证据可能提升写作者对争议的处理（这正是「推理在写作者」那段要的）。
- 验证（零 API）：对现有卡片重排后数 token；质量影响要跑一遍写作者（只重跑写作者，侦察复用——PSV 的角色分离让这种复用成为可能，这本身是一条可写的优点）。

### V4 · 跟随提及（PSV-M, mention-following）——提质量，有界，无需规划器
- 机制：侦察员的卡片结构里加一个字段 `mentions`：文档中出现的其它馆藏号 / 文献 id。第一波侦察结束后，纯机械地取「被提及、在目录里、未打开」的文档，最多 k 篇（k=5），派第二波侦察。不调用规划器。
- 保证：P2 不变；P3 从 ≤ 2+K+2 变为 ≤ 2+K+k+2，仍是常数。
- 预期：直接针对「计划没点那篇」的 40%——藏品记录常互相引用（比较件、同一画家的其他作品、来源链），被引而未读的正是硬负例排除与归属裁定最需要的。
- 这一条是「无为」的机械版：不再让规划器多想一轮，而是让语料自己指路。
- 风险：k 篇配额被无关提及占满；需要按「提及次数」排序。
- 验证：先回溯——在已有卡片 / 文档里数「被提及且未打开的金文档」有多少（如果接近 0 这条就不值得做）；再在 PSV 漏金的题上跑。

### V5 · 一次有界重规划（PSV-R1）——提质量，有界，比 V4 贵
- 机制：第一波后给规划器一份**紧凑的覆盖账本**（每个子问题：卡数、立场分布；被提及未打开的 id 列表；不给卡片正文），允许它最多补点 k 篇。只此一轮。
- 保证：P2 不变（账本 ≤ 500 token）；P3 常数加一。
- 预期：比 V4 多一次强模型调用，但能处理「提及链之外」的漏（例如子问题完全没卡时换检索词）。
- 验证：与 V4 同一子集对比；若 V4 已拿到大部分收益，就不要 V5（大道至简）。

### V6 · 按饱和分波停止（PSV-S）——省 token，可能增耗时
- 机制：按规划器排序把 K 篇分成每波 w 篇（w=8），一波结束若没有产生任何新卡（或没有覆盖新的子问题）就停止。
- 保证：不变。
- 预期：规划器排序好时省 20–40% 侦察 token；排序差时省不了。耗时增加一到两个侦察员的最大延迟。
- 这是「知止」：边际收益递减时停。
- 验证（回溯）：用现有轨迹按规划器顺序回放，算「若在第 w·i 篇后停」的金召回曲线。

### V7 · 两个见证人规则（PSV-C, corroboration flag）——提质量，近零成本
- 机制：写作者被要求对每个论断标注支撑它的卡数；只有一张卡的论断必须带限定语（「据 X 记录」）；两张以上独立文档支撑的论断可直接陈述。核验器可机械检查「直陈句至少两卡」。
- 保证：不变；核验器仍是集合检查。
- 预期：校准与不确定性表述改善，领域评委（R5）会喜欢；judge 分可能略升。
- 验证：只重跑写作者。

### V8 · 确定性一致性检查扩展——闸更强，零 token
- 机制：在「引句 ∈ 原文」之外加三条同样确定性的检查：
  (a) 卡片论断里出现的**年份 / 尺寸 / 馆藏号**必须出现在引句或原文中（正则）；
  (b) 卡片声称的**对象 id** 必须出现在原文（防止看着比较件写本件）；
  (c) 引句长度在 [8, 120] 词之间（太短歧义、太长是整段复制）。
- 保证：仍无模型。
- 预期：拦截艺术史里最常见的两类幻觉——日期与身份——而这两类是 judge 很难察觉的。
- 验证（回溯）：对 23,734 张卡跑一遍，报告每条规则的触发率，并人工抽 50 条看是否误拒。

### V9 · 侦察员输入切片——省 token，有风险
- 机制：长文档只给与子问题关键词命中的窗口（前后各 300 词），其余省略。
- 风险：窗口之外的证据丢失；与「逐字引句」互动微妙（引句仍可核验，但漏证据）。
- 验证（回溯）：现有卡片的引句落在命中窗口内的比例；若 ≥ 95% 可采用，但要在局限里写。

### V10 · 组合：PSV-lean = V1 + V2 + V3 + V4
- 预期：美元成本减半、token 减 20–30%、金读到率升 5–10 分、落地召回不降。
- 这是建议投稿后、或作为「扩展版」补的主实验；投稿版只需 V1 和 V2 的小规模数据即可写进讨论。

### 不建议做的
- 在闸里加 LLM 判「引句是否支持论断」：会把闸变成模型，丢掉「无模型核验」这个区别性性质；若要做，用小型 NLI 编码器且只**标记不删除**，放未来工作。
- ReAct 式的无界重规划循环：直接破坏 P2/P3。
- 把 PSV 包装成「新架构」：相关工作表已经说明骨架不新，新意在闸的位置、方式、对象与评测闭环。

## 三、设计原则及其来源（映射到机制，论文里最多留一句）

用户要求考虑道家、禅宗、基督教、社会主义、经济学等思想。下面每条写「思想 → 原则 → 对应机制 → 是否已在 PSV 中」。它们对设计有真实启发；但在 IPM 论文里引宗教典籍会被评委视为不专业，建议**只在讨论节保留一句原则化的表述**（见末尾），其余留给演讲 / 博客 / 中文技术报告。

| 来源 | 思想 | 设计原则 | 机制 | 状态 |
| --- | --- | --- | --- | --- |
| 道家 | 大道至简；少则得，多则惑 | 每个角色只看它需要的东西；核验用最简单的可判定规则 | 有界上下文；闸是字符串 / 集合检查 | 已有（P2、闸） |
| 道家 | 无为而治 | **以结构治理，而非以监督治理**：不在事后纠错，而是让错误无法发生 | 写作者只能引卡 → 不需要写后核验（对比 RARR / CoVe） | 已有（P1） |
| 道家 | 无为（顺势） | 让语料自己指路，而非让规划器多想 | V4 跟随提及（机械，不调规划器） | 新 |
| 道家 / 《道德经》 | 知止不殆 | 边际收益递减就停 | P3 固定终止；V6 饱和停 | 部分 |
| 禅宗 | 指月之指 | 引用是指，文档是月；指向空处的指是幽灵引用 | 定义 1 的叙述方式；轨迹审计检查「指确实指着月」 | 已有（可用作一句比喻） |
| 禅宗 | 看山是山 | 先把对象认成它自己，再谈意义 | 比较物扫描 = 身份裁定先于解释 | 已有 |
| 儒家 | 正名 | 名实相符：对象 id、年代、尺寸必须有出处 | V8 确定性一致性检查 | 新 |
| 儒家 | 言必信 | 说出的话必须能被兑现 | 逐字引句 | 已有 |
| 基督教 | 凭两三个见证人（申 19:15；太 18:16） | 独立佐证规则 | V7 两个见证人 | 新 |
| 基督教 | 是就说是（太 5:37） | 不渲染、不添 | 卡片 ≤120 词、逐字 | 已有 |
| 计划经济 vs 市场 | 计划高效但对局部知识盲（Hayek 知识问题）；市场自适应但无界 | 以计划为骨干，给局部知识一个**有界**的反馈口 | 规划器 = 计划；ReAct = 市场；V4/V5 = 有界反馈 | 新（这是论文里「固定计划」局限的最好解释框架） |
| 经济学 | 边际效用递减 | 阅读的停止规则 | V6 | 新 |
| 经济学 | 委托—代理与审计 | 审计者不能与被审计者同利；审计规则要外生 | 闸独立于模型、对六个家族通用 | 已有（可写进「为何不用 Citations 接口」） |
| 经济学 | 古德哈特定律 | 代理指标被优化后失效 | judge 分是代理；本文揭示它看不见落地差 | 已有（RQ 的论点） |
| 经济学 | 分工与交易成本（Smith / Coase） | 标准化的中间品降低协作成本 | 已核验证据卡 = 角色间唯一交换单位 | 已有（可点名） |
| 社会主义（治理） | 公开可审计 | 中间产物对人可读可查 | 卡片可人工审阅；轨迹全公开 | 已有 |

### 建议进论文的唯一一句（讨论节）
> PSV follows one governing principle: **govern by structure, not by supervision**. Errors that a post-hoc checker would have to catch are instead made unrepresentable—the writer cannot cite what no verified card contains—so the only reasoning that remains is the reasoning the task needs: decomposition before reading, evidence judgement during reading, and argument after it.

中文稿对应：「PSV 只遵循一条治理原则：以结构治理，而非以监督治理。写后核验者本来要去抓的错误，在这里被设计成无法表达——写作者引不了任何没有已核验卡的内容——于是留下来的推理只剩任务真正需要的那三处：读前分解、读中判证、读后论证。」

## 四、给「同样 token 更好 / 更少 token 同样好」的直接答案

- **更少 token、同样好**：V2（预筛）+ V3（去重分组）+ V6（饱和停）。全是零模型机制，不动任何保证；预计省 20–35% token。先做 V2 的回溯曲线，一个下午能出结论。
- **同样 token、更好**：V4（跟随提及）+ V7（两个见证人）+ V8（一致性检查）。V4 把省下来的侦察配额花在「被提及未打开」的文档上，正好打在 40% 漏金的病根上；V7、V8 不花 token。
- **更便宜、同样好**：V1（分层侦察）。不省 token 但省 40–60% 美元，而且能把「闸让便宜侦察员变安全」写成 PSV 独有的组合优势。

模拟（第三部分，`sim/`）在抽象模型下给出了这些变体的成本—召回前沿，用于决定先花预算跑哪个；它不是实验证据，论文里不要引用其数字。
